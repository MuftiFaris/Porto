# Porto

Personal portfolio landing page built with React, TypeScript, and Vite.

## Features

- Animated 3D wave background (canvas-based, mouse-reactive)
- Hero, About, Skills, Projects, and Contact sections
- Smooth scroll (Lenis) and scroll-triggered reveal animations
- Fully responsive, dark-mode design

## Getting started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Customize

Edit your own content in:

- `src/data/projects.ts` — your projects
- `src/data/skills.ts` — your skills/stack
- `src/components/Hero.tsx`, `About.tsx`, `Contact.tsx` — name, bio, and contact links
